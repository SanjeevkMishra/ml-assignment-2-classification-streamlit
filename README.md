## Problem statement

Build and compare five classification models for predicting whether a breast
tumour is benign (`B`) or malignant (`M`), then expose the saved models through
an interactive Streamlit application.

## Dataset description

The project uses the [UCI Breast Cancer Wisconsin (Diagnostic) dataset](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic).
It contains 569 instances, 30 numeric diagnostic features, an identifier, and a
binary diagnosis label. The identifier is excluded from modelling. The models
use a stratified 80/20 train/test split with `random_state=42`.

The model pipelines impute missing values where required and standardise
features for Logistic Regression, KNN, and SVM. The uploaded test file contains
the target column so that the app can calculate evaluation metrics.

## Models and evaluation

Run `python source_code/train_models.py` to train all five models, save them
under `model/`, and generate `metrics.json`. The metrics use malignant (`M`) as
the positive class.

### Observations

| Model | Observation |
|---|---|
| Logistic Regression | Strong linear baseline with 96.49% accuracy and 92.86% malignant recall. Its AUC of 0.996032 shows excellent ranking quality. |
| Decision Tree | Most interpretable model, but its 92.11% accuracy and 0.894841 AUC are lower than the other models, suggesting a less effective boundary for this dataset. |
| KNN | Scaling and local neighbourhoods produce 95.61% accuracy and 0.982474 AUC, but it misses slightly more malignant cases than Logistic Regression and SVM. |
| Naive Bayes | Perfect malignant precision and no benign false positives, but recall is only 83.33%, so seven malignant cases are missed in this split. |
| Support Vector Machine | Best overall test accuracy, F1, and MCC, with perfect malignant precision and 92.86% recall. The RBF boundary generalises well here. |

**Overall winner:** Support Vector Machine, because it has the highest accuracy
(0.973684), F1 (0.962963), and MCC (0.944155), while maintaining the joint
highest malignant recall (0.928571) and perfect precision.

## Streamlit application

`<PASTE_STREAMLIT_APP_URL_HERE>`

The app supports CSV upload, model selection, metric display, a confusion
matrix, and a classification report. It loads saved models and never retrains
on uploaded test data.
